#  Destiny Life

> É Um simulador de destinos desenvolvido para praticar JavaScript, HTML, CSS e Engenharia de Software.

---

##  Sobre o projeto

Destiny Life é um projeto desenvolvido com o objetivo de praticar desenvolvimento Front-end através da construção de uma aplicação interativa.

O projeto simula diferentes cenários de vida a partir das escolhas e informações fornecidas pelo usuário.

Além do aspecto divertido da aplicação, o principal objetivo é colocar em prática conceitos de programação, organização de código e boas práticas de desenvolvimento.

---

##  Objetivos do projeto

- Praticar JavaScript na construção de aplicações reais.
- Aprender manipulação do DOM.
- Desenvolver lógica de programação.
- Aplicar boas práticas de Engenharia de Software.
- Evoluir o projeto através de Sprints.

## Sprint 07  Reavaliar a experiência do usuário (UX) antes de iniciar a implemtação das animações.
###  Decisões tomadas

- Redefinição da Experiência do Usuário (UX), 
- Manter a arquitetura atual da Engine (sem alterações).
- Definido que o algoritmo continuará processando todo o resultado nos bastidores.
- A experiência visual será separada da lógica do jogo.
- O usuário acompanhará visualmente o processo de eliminação dos elementos.
- A narrativa será utilizada apenas na tela final, e não durante todo o processo.
